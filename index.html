⚙️ Setup & Installazione

Passo 1 — Firebase (sync cloud)

Vai su console.firebase.google.com, crea un progetto gratuito "scadenzario-balbusso", abilita Realtime Database in modalità test, poi torna qui e incolla la tua config nel campo sotto.

Passo 2 — Hosting gratuito su GitHub Pages

1. Crea un repository pubblico su github.com (es. scadenzario)
2. Carica questo file index.html e manifest.json nella root
3. Vai in Settings → Pages → Source: main branch / root
4. Il tuo URL sarà: tuonome.github.io/scadenzario

Passo 3 — Installa come app su iPhone

1. Apri l'URL su Safari (obbligatorio, non Chrome)
2. Tocca il pulsante Condividi ⬆️
3. Scorri e tocca "Aggiungi a schermata Home"
4. L'app appare come icona nativa ✅

Passo 4 — Installa su Windows (Chrome)

1. Apri l'URL su Chrome
2. Clicca l'icona ⊕ Installa app nella barra indirizzi
3. L'app si apre come finestra nativa, senza browser ✅
